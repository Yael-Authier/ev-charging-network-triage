\# EV Charging Network Triage



Voltora operates 40 EV charging stations and can dispatch 5 technician visits

per week. This repository decides which ones.



\*\*Status: work in progress.\*\* The world configuration is frozen; the data

generator, analysis and decision app are not built yet. No findings are

published in this repository at this stage.



Voltora, its stations, staff, metrics, incidents and business rules are

\*\*entirely fictional\*\*. All data in this project is synthetic and generated by

`generator/`. Any resemblance to a real company is unintended.



\## Reproduce



```bash

python -m venv .venv

source .venv/bin/activate      # Windows: .venv\\Scripts\\Activate.ps1

pip install -r requirements.txt

python tasks.py check

```
